# Data Directory

This directory stores the dataset files supplied by the ABTalks Vibe Code Hackathon organizers for Problem Statement 2 ("The Interview Agent").

## Required Files

Please place the supplied JSON files directly into this directory:

1. `curriculum.json` — The 31-day learning curriculum JSON file.
2. `candidates.json` — The candidate profiles JSON file.

> **Note**: Do not invent or commit fabricated mock data here. The actual files provided by the organizers should be placed here when running locally or deploying.
